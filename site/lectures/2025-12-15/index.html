Lecture 04 · Data & documents

From handwritten notes to working prototypes

Explore equations, data visualisation and a PDF viewer built with Gemini.

InstructorMattia Montanari
Class date15 December 2025
SeriesUniversity of Oxford
IT Services · Digital Capabilities

This class explored three uses of Gemini: transcribing mathematical notes, turning data into visualisations, and generating a browser-based PDF viewer. Each task produces a different kind of output, with a different way to check it.

Source of these notes

Adapted from the repository’s class notes and saved artifacts. No transcript has been supplied yet.

Explore the original materials ↗

From handwriting to mathematical notation

The class notes record a successful transcription of a handwritten Navier–Stokes equation into LaTeX. The example uses index notation, including commas to denote partial derivatives.

ρUi,t+ρUkUi,k=−P,i+μUi,jj+fi
\rho U_{i,t} + \rho U_{k} U_{i,k} = -P_{,i} + \mu U_{i,jj} + f_{i}

Context can help a model interpret an unclear symbol, but it can also lead to a plausible-looking correction that changes the intended equation. Compare the output with the original before using it in a document.

Keep the source

The handwritten input is not in this repository. The equation and the class account are available; this page cannot independently verify the transcription.

A chart and an artistic image have different jobs

The session used Gemini’s code execution to generate charts from CSV data, and image generation to create an artistic interpretation in the style of a Roman mosaic.

A data chart should let the reader check labels, quantities and scale. An artistic image can communicate a theme, but numerical fidelity should be verified rather than inferred from its appearance.

Illustrative data created for this learning tool, not the original class CSV. Use a header and up to 12 rows of labels and non-negative values. The values remain the same when the axis changes.

From a request to a PDF viewer

The notes describe an application with PDF upload, document navigation, light and dark modes, and a responsive layout. A recording of the viewer was saved, along with an account of receiving deployment instructions.

Generated deployment instructions are a starting point. A working prototype still needs to be checked with representative files, on different screen sizes, and in its intended hosting environment.

Match the check to the output

For an equation, inspect the notation. For a chart, inspect the data and axes. For an application, exercise its behaviour. Producing an output quickly is useful; understanding how to assess it makes that output usable.
